# AI Based Smart Agriculture Monitoring and Automation System

## 📌 Project Overview

The AI Based Smart Agriculture Monitoring and Automation System is an intelligent agriculture solution designed to help farmers identify tomato leaf diseases using Artificial Intelligence and Image Processing.

The system analyzes a tomato leaf image and predicts the disease, confidence level, affected area, plant health score, and severity. It also provides treatment recommendations based on the detected disease.

## 🚀 Features

- Tomato leaf disease detection using AI
- Disease classification
- Confidence percentage
- Affected area estimation
- Plant health score
- Disease severity analysis
- Treatment recommendations
- Web-based interface
- FastAPI backend for AI prediction
- Mobile application integration

## 🦠 Diseases Detected

The trained model can classify:

- Bacterial Spot
- Early Blight
- Healthy
- Late Blight
- Leaf Mold
- Septoria Leaf Spot

## 🛠️ Technologies Used

- Python
- TensorFlow
- OpenCV
- FastAPI
- HTML
- CSS
- JavaScript
- Machine Learning
- Image Processing

## ⚙️ How It Works

1. The user selects or captures a tomato leaf image.
2. The image is sent to the backend.
3. The trained AI model analyzes the image.
4. The system predicts the tomato leaf condition.
5. The system calculates confidence, affected area, health score, and severity.
6. A treatment or recommendation is provided to the user.

## 📊 Model Performance

The trained model achieved approximately *89.68% test accuracy*.
